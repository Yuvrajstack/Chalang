Empowering Students With Verified Opportunities

YARD (Youth Academic & Resource Directory) is a smart academic and opportunity management platform designed for students, teachers, employers, and institutions. The platform provides verified educational resources, scholarship opportunities, internships, career guidance, and academic support in one place.

About The Platform

Centralized Student Guidance System

YARD helps students reduce confusion while selecting exams, careers, universities, and opportunities. It combines academic resources with verification systems to ensure trust and safety.

Integrated Opportunity Management

Teachers and employers can post verified opportunities such as internships, hackathons, workshops, scholarships, and jobs. Students can search and filter opportunities according to categories and interests.

Secure Verification & Monitoring

The platform includes a secure link verification module that checks external links using a safety scoring algorithm. Unsafe links are blocked while suspicious links generate warnings.

Core Modules

Authentication Module

Secure login system for teachers, employers, HR teams, and students using authentication APIs and encrypted credential management.

Opportunity Module

APIs for posting, updating, deleting, and managing opportunities with category-based filtering systems.

Link Verification

Safety scoring algorithms verify external resources and educational links to protect students from harmful websites.

Secure Browser Logging

Tracks access logs, monitoring data, suspicious activity, and security analytics for better platform reliability.

Technology Stack

Frontend

HTML, CSS, JavaScript, and React are used to create interactive and responsive user interfaces.

Backend

Spring Boot handles APIs, authentication systems, business logic, and opportunity management.

Database

MySQL stores teacher credentials, opportunities, verification logs, and user information securely.

Security

Link scanning systems and verification modules improve trust and reduce malicious content risks.
